Local-first GAIA agent

A bounded research agent that runs with Python and Ollama, verifies web sources, validates exact-answer formats, and keeps evaluation separate from leaderboard submission.

Zero-cost architecture: this Static Space publishes the demo and source. Ollama evaluation stays on your computer; no model, paid API, token, or benchmark answer runs in the browser.
1

Trial question

Start with one item before committing local compute.

python projects/gaia-final-agent/cli.py run --limit 1 --output gaia-trial.json
2

Review safely

See failures and rejected answers without submitting.

python projects/gaia-final-agent/cli.py review --answers gaia-answers.json --failed-only
3

Retry selectively

Preserve prior attempts and rerun only one task.

python projects/gaia-final-agent/cli.py retry --answers gaia-answers.json --task-id TASK_ID
