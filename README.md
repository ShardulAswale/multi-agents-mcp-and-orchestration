# Hugging Face AI Agent Challenges

Private, hands-on learning repository for the Hugging Face AI Agents course. Each lesson pairs concepts and pseudocode with runnable challenges and tests.

## Structure
- `lessons/`: numbered learning notes and pseudocode
- `challenges/`: runnable implementations
- `tests/`: deterministic regression tests
- `projects/`: capstone agent applications

## Start here
1. Read [Agent fundamentals](lessons/01-agent-fundamentals/README.md).
2. Read [Tool calling](lessons/02-tool-calling/README.md).
3. Try [Flight filtering challenge](challenges/01-flight-filtering/README.md).
4. Run `python -m unittest discover -s tests -v`.
